# DOC-002 Glossary

| Term | Meaning in these documents |
| --- | --- |
| Aircraft status | Flying, grounded or in maintenance, as entered by the program. |
| Alternate part number | A part number the program has entered as interchangeable with another. SpareWing never decides interchangeability itself. |
| Baseline | A set of document versions the owner has approved together, recorded in a review record. |
| Blocked (Prepped) | A lot that must not be packed, with the reason shown. |
| Candidate (SpareWing) | A part or pilot that meets the entered rules and is offered for a qualified person to verify. Never an approval. |
| Clinician | A licensed prescriber or pharmacist who holds final authority over the mission pharmacy (owner, 2026-11-10). |
| Cold chain | Storage that must stay within a refrigerated range. Cold-chain items are excluded from this build (ADR-007). |
| Comparable alternative | Another available medicine in the same therapeutic class, offered for a clinician to consider. Comparable is never equivalent (ADR-003). |
| Controlled substance | A medicine under drug-control scheduling. Always blocked. |
| Currency (pilot) | The recency and validity of a pilot's ratings and checks, as entered by the program. |
| Decision support | Software that proposes and explains; a qualified person decides (ADR-002). |
| Draft | Any generated text or list that is not final until the responsible person marks it reviewed. |
| Discard list | Lots past their expiry on the date of the check, set aside to be discarded and never packed (owner, 2026-11-11). |
| Enteral and topical scope | The routes in scope for this build: by mouth, under the tongue, rectal, feeding tube, skin, eye, inhaled, nasal, vaginal and ear, with no cold chain. Injections and infusions are out (owner, 2026-11-10 and 2026-11-11). |
| Exchange | Another formulation or strength of the same medicine, offered to meet a floor item; it counts only when the clinician accepts it (owner, 2026-11-11). |
| Eligible (Prepped) | A lot that meets every rule for the trip. Still subject to clinician sign-off. |
| Floor list | The mission's minimum set of essential medicines and target quantities, chosen by the lead clinician (owner, 2026-11-10). |
| Flight base director | The person in charge of a mission aviation base, with authority over schedule changes (owner, 2026-11-10). |
| Go or No go | Prepped's indicator of whether the floor list and required documents are met. An indicator only; the lead clinician or team leader decides whether to deploy (owner, 2026-11-10). |
| Golden example | A recorded input and expected AI output used to test an AI step without calling a model. Drawn only from the development partition. |
| Held-back set | One third of the generated data, sealed and never used for building, tuning or prompts, used once for pre-release confirmation (DAT-002). |
| Lot | A quantity of one medicine with one lot number and expiry date, from one donor. |
| Mutation score | The share of deliberately introduced code faults that the tests detect (Stryker). |
| Needs review (Prepped) | A lot whose data is incomplete, such as no expiry date. Never counted as usable. |
| Open decision | A question only the owner can answer, listed in DOC-003. |
| Readiness | How ready a trip is: the Go or No go indicator (SYS-112) and, beside it, a graphic meter weighting need coverage and documents 70/30 (SYS-106). |
| Release blocker | An open decision or failed check that stops the hackathon submission or a release. |
| Review copy | An uncontrolled copy of a document on claude.ai, stamped with ID, version and commit. |
| Rule card | A sourced, dated note of a destination country's import requirements. |
| Safety-critical | Code or a requirement whose failure could contribute to harm (ADR-006). |
| Serviceable | A part the program has marked fit for use. |
| Sign-off | The responsible person's recorded confirmation in the app. |
| Supplement | A medicine the lead clinician adds beyond the floor list. Never affects Go or No go. |
| Synthetic data | Data generated by `packages/synth`, containing no real person, patient or record. |
| TBD | Content the owner has not yet decided. Never filled in by guesswork. |
| Unknown (SpareWing) | A candidate whose data is incomplete. Shown, never silently included or excluded. |
