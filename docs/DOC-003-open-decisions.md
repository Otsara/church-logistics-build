# DOC-003 Open decisions and release blockers

Every question only the owner can answer is listed here, open or closed. Nothing in code or documents guesses an answer to an open decision. A decision is closed only with the owner's answer in the conversation, recorded as "(owner, YYYY-MM-DD)", and carried into the items it affects in the same change.

`Blocks:` says what cannot happen while the decision is open:

- `submission`: the hackathon submission (November 27, 2026, 11:59 PM ET) cannot be completed.
- `real-world use`: the prototype must not be used with real people, medicines or aircraft.
- `none`: improves the product but blocks nothing.

The release-blocker list below is generated by `pnpm docs:update`.
