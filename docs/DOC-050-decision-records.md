# DOC-050 Decision record index

Decisions that cross documents or affect safety are recorded as ADRs in `docs/adr/`, one file each, with context, options and consequences. An ADR's status is `Proposed`, `Accepted` (with "(owner, YYYY-MM-DD)"), `Superseded` (naming its successor) or `Rejected`. An ADR is never edited after it is accepted, except to mark it superseded; a changed decision gets a new ADR.
