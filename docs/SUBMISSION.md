# Submission checklist

One line per hackathon submission requirement in `docs/BUILD_SPEC.md` (H-1 to H-7). Tick a line only when the requirement is met, and add the evidence after it: a link, a date, a file or a check result. `pnpm check:trace --strict` fails while any line is unticked. The owner ticks the lines for the submission itself (H-1, H-2, H-6, H-7).

Submission page: https://aiforchurch.com/hackathon. Deadline: November 27, 2026, 11:59 PM ET.

- [ ] H-1 Deadline and build window. Evidence: submission date and time; first commit dated inside the window.
- [ ] H-2 Demo video of 5 minutes or less on YouTube, Vimeo or Loom. Evidence: link and length.
- [ ] H-3 AI made it and AI is in it. Evidence: the video timestamps where the AI steps run and a person reviews a draft.
- [ ] H-4 Honest, kind and safe. Evidence: the description's statement about placeholder rule values and reviewer status; no "approved" anywhere (lint).
- [ ] H-5 Sample data only. Evidence: the demo data comes from `packages/synth` with a stated seed.
- [ ] H-6 Submission contents. Evidence: project name, description, track, video link, live demo link, repository link or the decision not to include one.
- [ ] H-7 One project, Open Track. Evidence: the track chosen on the form; where the description covers each of the four criteria.
